# LeadFinder for Windows

[Browse the unpacked files](LeadFinder) or [download the ZIP](LeadFinder-Windows.zip).

1. Download and extract `LeadFinder-Windows.zip`.
2. Open the extracted `LeadFinder` folder and double-click `INSTALL_LEADFINDER.bat`.
3. After setup, use the **LeadFinder** desktop shortcut to open the app.

Put the separately supplied `.env` file beside the installer before setup, or enter the supplied API keys when prompted. Initial setup requires internet to download Python if needed, application packages, and the reference browser.

After installation, use **API keys** in the app to replace, test, or remove the DeepSeek, Google Maps, and Pexels keys. Blank fields keep saved keys. Changes apply to new requests immediately without restarting.

Use **Sort by** to order the saved list by priority, score, or business name. **Delete business** removes the selected entry, while **Clear list** removes all saved businesses, including those hidden by filters. Both ask for confirmation. Removed businesses and their saved websites remain in the installed app's `outputs/deleted_leads` folder and are excluded from future CSV exports.

The ZIP and unpacked folder contain the application files. Credentials, saved businesses, generated demos, and local environments are excluded.

These are distribution snapshots generated by `tools/build_windows_zip.py`; the main application source is maintained at the repository root.
